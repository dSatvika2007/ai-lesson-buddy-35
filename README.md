# AI Lesson Hub

Build a web app called “AI Teacher” with the requested home upload/topic form, configurable AI lesson generation, concept-by-concept lesson flow with AI answer feedback, multiple-choice final quiz, and final learning report. Use React and a clean modern UI. Enable Lovable Cloud because AI calls and file handling need a backend; keep the AI API key server-side as an environment variable the user can set. Include a fixed placeholder intro video player above the lesson content, ready for a link/file later. Build the full experience and sensible error/loading states.

This project was built with [Lovable](https://lovable.dev).
